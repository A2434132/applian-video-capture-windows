## What Is Applian Replay Video Capture?

Applian Replay Video Capture provides a Windows-based way to create recordings from a full monitor, a particular application, or a user-defined screen area. It can also capture streamed material played on the local computer.

Alongside display recording, the application can take in system and microphone audio, place webcam footage over the recording, and perform straightforward edits after capture. These capabilities support tutorials, software demonstrations, walkthroughs, streaming clips, and similar day-to-day recording projects.

---

## Key Capabilities

- Capture an entire screen, an individual window, or a manually selected area
- Record computer audio and microphone input together with the video
- Arrange recordings to begin later or repeat on a schedule
- Overlay webcam video so the presenter appears in the finished recording
- Export recordings as MP4, AVI, WMV, FLV, or MOV files
- Control recording with keyboard shortcuts and cursor visibility options
- Shorten footage using the built-in trim and cut editor
- Handle streamed-video capture as well as ordinary desktop recording

## Recording Workflow

A standard session can be set up as follows:

1. Launch Applian Replay Video Capture.
2. Select the capture target:
   - entire display
   - application window
   - custom region
3. Choose any required audio inputs:
   - system audio
   - microphone
4. If desired, activate the webcam overlay and cursor settings.
5. Configure shortcut keys or create a recording schedule for unattended capture.
6. Start recording and stop it once the session is complete.
7. Make any needed cuts or trims before exporting the result.

For example, you can:

- Record a software demonstration while keeping the cursor visible.
- Add spoken narration through a microphone.
- Export the finished recording to MP4 for sharing.
- Remove unwanted material from the start and end before publication.
